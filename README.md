# urban-biodiversity-dce
Data and code for urban biodiversity DCE.
This repository contains Python scripts and Stan code, data, and documentation for the analysis of willingness-to-pay for increased indicator species biodiversity sightings in Greater Manchester, United Kingdom. First HBL2.stan has to be run and the .exe saved in the code folder. After this the notebook scripts can be used, BUT with adjustment to the user's local directory in the loadindata files.

## Contents
- `/code/` — Stan model files  
- `/data/` — Processed data  
- `/notebooks/` — Jupyter notebooks  
- `/scripts/` — code, data and notebook folders contain respective python scripts
